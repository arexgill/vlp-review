Research context

A practical sketch of verifiable literate programming

This POC is inspired by Yuan et al., Guiding Human Validation of LLM-Generated Code via Verifiable Literate Programming, arXiv:2607.02333v1. The study reports VLP improving pass@1 from 28.7%–73.2% to 65.4%–93.5% across its evaluated settings.

This tool uses local AST analysis and transparent heuristics. It is not the full research implementation: there is no LLM mismatch detector, API knowledge base, formal literate grammar, or bounded model checking.
